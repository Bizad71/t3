# واژه‌یار — نسخهٔ GitHub Pages

## راه‌اندازی
1. این فایل‌ها را در ریشهٔ یک مخزن GitHub قرار بده: `index.html`، `style.css` و `script.js`.
2. در مخزن، وارد **Settings → Pages** شو.
3. در بخش Build and deployment، گزینهٔ **Deploy from a branch** را انتخاب کن؛ شاخهٔ `main` و پوشهٔ `/(root)` را بزن و ذخیره کن.
4. پس از انتشار، لینک GitHub Pages مخزن را باز کن.

## امکانات و محدودیت‌های واقعی
- ورودی سایت فارسی است؛ سرویس MyMemory تلاش می‌کند معنی انگلیسی را برگرداند.
- جمله‌ها از الگوهای انگلیسی درست و از پیش نوشته‌شده ساخته می‌شوند و با هر بار زدن دکمه، الگوی بعدی انتخاب می‌شود. این نسخه مدل هوش مصنوعی نیست و ادعا نمی‌کند جملهٔ آزاد هوش مصنوعی می‌سازد.
- تلفظ با قابلیت گفتار مرورگر (`SpeechSynthesis`) انجام می‌شود؛ صدای موجود به مرورگر و دستگاه بستگی دارد.
- تصویر از Wikimedia Commons جست‌وجو می‌شود؛ برای دریافت معنی و تصویر، اینترنت لازم است.
- این سایت سرور اختصاصی ندارد و کلید محرمانه‌ای در کد قرار نمی‌دهد. سرویس‌های عمومی ممکن است محدودیت یا قطعی موقت داشته باشند.
